# Skills developed

The [practical experiments](../practical/) document hands-on work with:

- LLM API and local model use
- Tokenization and token cost analysis
- Model evaluation with a fixed question set
- Next-token probabilities and attention
- Logging and comparing model responses

The [project](../project/) applies these concepts to Kisaan Krushi V-01 GPT. This folder can hold future skill notes and evidence without mixing them with experiment submissions or project artifacts.
